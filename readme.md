# Local Image Converter with Custom Size Limit

**Local Image Converter** သည် မိမိ၏ ကွန်ပျူတာ သို့မဟုတ် ဖုန်းထဲတွင်တင် Format ပြောင်းလဲခြင်းလုပ်ငန်းစဉ်များကို ရာနှုန်းပြည့် လုပ်ဆောင်ပေးသော Client-side Web Tool တစ်ခု ဖြစ်သည်။ Server ပေါ်သို့ ပုံများ တင်ပို့ခြင်း လုံးဝမရှိသည့်အတွက် ပုံစံဖျက်ခြင်းနှင့် ကိုယ်ရေးအချက်အလက် (Privacy) အတွက် စိတ်ချရဆုံး ဖြစ်သည်။

## Features (ပါဝင်သော လုပ်ဆောင်ချက်များ)
- **Batch Conversion:** ပုံအများကြီးကို တစ်ပြိုင်နက်တည်း (Bulk) ရွေးချယ်၍ Format ပြောင်းလဲနိုင်သည်။
- **ZIP File Support:** ပုံများစွာ ပါဝင်သော ZIP ဖိုင်ကို တိုက်ရိုက်ဆွဲထည့် (Drag & Drop) ပြီး အထဲမှ ပုံများကို ထုတ်ယူပြောင်းလဲနိုင်သည်။
- **Custom File Size Limit (KB):** မိမိအလိုရှိသော ဖိုင်ဆိုဒ် ပမာဏကို (ဥပမာ - 500 KB, 1024 KB) စိတ်ကြိုက် ရိုက်ထည့် ကန့်သတ်နိုင်သည်။
- **Smart Compression Engine:** သတ်မှတ်ထားသော ဖိုင်ဆိုဒ် ကန့်သတ်ချက်အတွင်း ဝင်ဆံ့စေရန် အရည်အသွေး (Quality) ကို နောက်ကွယ်မှ အလိုအလျောက် အနုစိတ် ချုံ့ပေးသည်။
- **Multiple Formats:** WebP, JPG/JPEG နှင့် PNGFormat များသို့ အလွယ်တကူ ပြောင်းလဲနိုင်သည်။
- **Transparent Image Fix:** နောက်ခံကြည်လင်သော (Transparent) PNG ပုံများကို JPG ပြောင်းသည့်အခါ နောက်ခံမည်းသွားခြင်းမရှိစေရန် အဖြူရောင်ခံပေးသည့် စနစ် ပါဝင်သည်။
- **Append & Preview Mode:** ပုံများကို ထပ်ခါထပ်ခါ ထပ်တိုးရွေးချယ်နိုင်ပြီး၊ မလိုချင်သော ပုံများကို အမှိုက်ပုံးခလုတ်ဖြင့် ပြန်လည်ဖယ်ထုတ်နိုင်သည်။

## Technology Used
- HTML5 / CSS3 (Responsive Design)
- JavaScript (Vanilla JS - Client Side)
- [JSZip Library](https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js) (For ZIP processing)

## How to Use (အသုံးပြုနည်း)
1. `index.html` ဖိုင်ကို Double-click နှိပ်၍ Browser တွင် ဖွင့်ပါ။
2. ပြောင်းလဲလိုသော ပုံများ သို့မဟုတ် ZIP ဖိုင်ကို ဆွဲထည့်ပါ သို့မဟုတ် ရွေးချယ်ပါ။
3. ပြောင်းလဲလိုသည့် Format နှင့် အမြင့်ဆုံး ဖိုင်ဆိုဒ် ကန့်သတ်ချက် (KB) ကို သတ်မှတ်ပါ။
4. **"ဖိုင်များကို စတင်ပြောင်းလဲမည်"** ခလုတ်ကို နှိပ်ပါ။
5. လုပ်ငန်းစဉ်ပြီးဆုံးပါက ပြောင်းလဲပြီးသား ပုံများကို ZIP ဖိုင်အဖြစ် အလိုအလျောက် ဒေါင်းလုဒ် ပြုလုပ်ပေးသွားမည် ဖြစ်သည်။

## Privacy & Security
ဒီ Tool သည် မည်သည့် Server သို့မျှ ပုံများကို ပေးပို့ခြင်းမရှိဘဲ သင့် Browser ထဲတွင်သာ Local 100% အလုပ်လုပ်ခြင်း ဖြစ်သောကြောင့် အင်တာနက်မရှိဘဲ Offline လည်း အသုံးပြုနိုင်ပါသည်။
